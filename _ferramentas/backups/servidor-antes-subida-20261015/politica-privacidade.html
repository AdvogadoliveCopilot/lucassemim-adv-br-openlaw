🛡️ SIGILO ADVOCATÍCIO GARANTIDO

Todas as informações compartilhadas através de nossos formulários ("Dossiê", "Diagnóstico") são protegidas pelo Sigilo Profissional (Art. 7º, XIX, Lei 8.906/94). Seus dados jamais serão vendidos ou expostos.

Coletamos apenas o necessário para a prestação do serviço jurídico:
  • Identificação: Nome, CPF, Telefone e E-mail.
  • Dados Processuais: Número de processo e relato dos fatos para triagem.
  • Navegação: Cookies técnicos para funcionamento do site e análise anônima (Google Analytics).

  • Para realizar a triagem técnica do seu caso (Diagnóstico Live).
  • Para entrar em contato via WhatsApp ou E-mail.
  • Para liberar acesso à Área do Cliente (Painel de Transparência).

Nosso site utiliza criptografia SSL (Cadeado Seguro) em todas as páginas. Os dados sensíveis de formulários não são armazenados em banco de dados público; são transmitidos diretamente para nossa central segura via API criptografada.

Você tem o direito de solicitar a confirmação, acesso, correção ou eliminação dos seus dados a qualquer momento. Para isso, basta entrar em contato com nosso Encarregado de Dados (DPO).
